# Icons

GPL-3.0 icon masks copied from Telegram Desktop (`Telegram/lib_ui/icons`, `Telegram/Resources/icons`).

Telegram's paper-plane logo is a trademark and is not shipped: `intro_plane_*.png` are transparent
placeholders of the original sizes (the intro screen shows the Rustgram icon instead), and
`chat/unsupported_plane.svg` is an original info-circle drawing.
